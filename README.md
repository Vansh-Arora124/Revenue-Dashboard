
# 🚕 UrbanCab Fare Analysis Dashboard

## 📌 Project Overview

UrbanCab Fare Analysis is an Excel-based data analytics project
that analyzes ride demand, revenue, pricing, vehicle performance,
traffic conditions, and city-level performance.

## 🎯 Project Objective

To analyze UrbanCab ride data and identify:

- Ride demand patterns
- Revenue trends
- Average fare
- Distance patterns
- Demand/Supply ratio
- Vehicle performance
- Traffic impact
- City-level performance

## 🛠️ Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Slicers
- Data Cleaning
- Data Analysis

## 📊 Dashboard KPIs

- Total Rides
- Total Revenue
- Average Fare
- Average Distance
- Average Demand/Supply Ratio

## 📈 Dashboard Analysis

The dashboard includes:

- Revenue by City
- Rides by Vehicle Type
- Rides by Day of Week
- Demand by Hour
- Rides by Traffic Level
- Monthly Revenue

## 📂 Project Files

- `UrbanCabFare.csv` — Raw dataset
- `UrbanCab_Dashboard.xlsx` — Excel dashboard
- `README.md` — Project documentation

## 💡 Key Insights

The dashboard helps identify patterns in ride demand,
revenue, pricing, vehicle usage, traffic conditions,
and city-level activity.

## 📌 Conclusion

This project demonstrates how Excel can be used to transform
raw ride data into an interactive business dashboard for
data analysis and decision-making.
